# E-Book Local Book Manager

一个面向 Windows 的本地电子书管理与阅读应用，帮助用户从文件夹导入书籍、整理书库，并在本地完成阅读。应用优先保护用户数据，书籍源文件保持只读。

## 主要功能

- **文件夹导入**：选择文件夹批量添加可识别的书籍文件，每个文件夹可作为一个书单管理。
- **本地书库管理**：支持书籍、收藏、书单和阅读进度等信息持久化保存。
- **多种格式阅读**：支持 TXT、图片文件夹、ZIP 图片书和 PDF。
- **阅读进度保存**：关闭阅读窗口或翻页时保存进度，方便下次继续阅读。
- **收藏与筛选**：支持收藏书籍，并按书名搜索和筛选书库内容。
- **独立阅读窗口**：默认在独立阅读窗口中打开书籍，同时保留内嵌阅读模式支持。
- **主题与背景设置**：支持应用主题和阅读背景调整。
- **中英文资源**：提供中文和英文界面资源。

## 技术栈

- .NET 10
- WinUI 3 / Windows App SDK
- SQLite
- CommunityToolkit.Mvvm

## 数据与隐私

- 书籍、收藏、书单和阅读进度等业务数据使用 SQLite 持久化。
- 应用设置使用本地 JSON 文件保存。
- 用户导入的源文件只读，不会被应用修改。

## 运行环境

Windows 10 版本 1809（10.0.17763）或更高版本。
